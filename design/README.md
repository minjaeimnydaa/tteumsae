# 디자인 참고자료

- `design-system-v1.0.svg`: 색상, 타이포그래피, 컴포넌트, 주요 화면
- `figma-flow-2026-07-29.mp4`: 이동 틈새/근처 틈새 탐색의 애니메이션과 흐름

SVG는 브라우저 또는 Figma에서 열 수 있습니다. 파일 안에 화면 이미지가
base64로 포함되어 있어 별도 이미지 링크 없이 표시됩니다.

## 사용 원칙

- 이 폴더는 제품 의도와 시각 기준을 설명하는 참고자료입니다.
- 실제 구현 여부는 `docs/03_FEATURE_MATRIX.md`를 기준으로 판단합니다.
- 영상과 SVG 이후에 논의된 결과 화면·경유지 UI는 아직 원본 디자인 파일에 모두 반영되지 않았습니다.
- 대화에 첨부된 임시 PNG 경로는 다른 컴퓨터에서 열리지 않으므로 Git 문서에서 참조하지 않습니다.
- 새 화면이 확정되면 원본 디자인 파일과 구현 상태 문서를 같은 변경에서 갱신합니다.

공식 브랜드 Primary는 `#E60F33`이며, 앱 토큰은 `android/app/src/main/java/com/tteumsae/app/ui/theme/Theme.kt`에 있습니다.
