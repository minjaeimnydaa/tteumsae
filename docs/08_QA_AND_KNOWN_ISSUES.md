## 2. 인수 직후 자동 검증

### Android

```powershell
cd android
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat compileDebugKotlin
.\gradlew.bat compileDebugUnitTestKotlin
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleDebug
```

예상 상태:

- 첫 두 컴파일과 APK 빌드는 성공해야 합니다.
- `testDebugUnitTest`의 기존 클래스 로딩 오류를 먼저 재현합니다.
- 영문·공백 없는 경로에서도 실패한다면 Gradle worker classpath와 테스트 출력 디렉터리를 조사합니다.

### 백엔드

```powershell
cd backend
pnpm install --frozen-lockfile
pnpm test
pnpm run check
```

모든 테스트와 프로젝트 검사가 통과해야 Preview 배포를 진행합니다.

## 3. Android 핵심 스모크 테스트

각 항목은 실제 Android 기기에서 확인합니다.

### 설치와 홈

- [ ] 새로 설치 후 앱 이름이 `틈새`로 표시된다.
- [ ] 홈에서 카카오 지도가 정상 로드된다.
- [ ] 네이티브 앱 키가 없을 때 플레이스홀더와 설정 필요 안내가 나온다.
- [ ] 첫 진입 소개 팝업이 나타난다.
- [ ] `오늘 하루 보지 않기`가 같은 날짜에 유지된다.
- [ ] 하단의 장소 찾기·장소 둘러보기·설정 탭이 전환된다.

### GPS와 위치 권한

- [ ] 권한 미허용 상태에서 GPS 버튼을 누르면 시스템 권한 요청이 뜬다.
- [ ] 정확한 위치 허용 후 지도 카메라와 마커가 현재 위치로 이동한다.
- [ ] GPS 버튼을 다시 누르면 활성 상태가 해제된다.
- [ ] 화면을 이동했다가 돌아와도 의도한 GPS 상태가 유지된다.
- [ ] 위치 서비스가 꺼져 있으면 시스템 설정 안내가 나온다.
- [ ] 한 번 거부했을 때 재요청 가능한 흐름이 동작한다.
- [ ] `다시 묻지 않음` 후 앱 설정으로 이동하는 버튼이 제공된다.
- [ ] 권한을 설정에서 켠 뒤 앱으로 돌아왔을 때 정상 복구된다.
- [ ] 위치 취득 12초 timeout에서 사용자에게 오류를 보여준다.

### 장소와 경로 설정

- [ ] 이동 모드에서 출발지는 현재 위치로 자동 설정된다.
- [ ] 현재 위치를 실제 행정 주소로 바꿔 표시한다.
- [ ] 출발지를 검색 장소로 변경할 수 있다.
- [ ] 목적지 검색 결과가 입력 350ms 후 나타난다.
- [ ] 검색 결과 최대 5개가 이름과 주소를 표시한다.
- [ ] 이동 모드 목적지가 강원도 밖이면 진행을 차단한다.
- [ ] 근처 모드 기준 위치가 강원도 밖이면 진행을 차단한다.
- [ ] 모드 전환 시 출발·목적지 상태가 올바르게 변경된다.
- [ ] BottomSheet를 아래로 완전히 숨기면 홈으로 돌아간다.
- [ ] 시트가 보일 때만 이전·다음 버튼이 보인다.

### 시간과 추천 의도

- [ ] 슬라이더가 15분~6시간, 15분 간격으로 움직인다.
- [ ] 직접 입력이 15분~24시간을 허용한다.
- [ ] 15분 미만, 24시간 초과, 문자 입력을 안전하게 처리한다.
- [ ] 이동 모드는 자동차로 고정된다.
- [ ] 근처 모드는 도보·자동차를 바꿀 수 있다.
- [ ] 안전 여유 10·15·20·30분이 요청에 반영된다.
- [ ] 추천 의도 여섯 종류가 올바른 카테고리로 변환된다.
- [ ] `지금은 음식 제외`에서 음식점·카페가 나오지 않는다.

### 로딩·오류·빈 결과

- [ ] 정상 네트워크에서 로딩 후 결과로 이동한다.
- [ ] 네트워크를 끊으면 실패한 작업과 재시도 버튼이 보인다.
- [ ] 재시도 후 정상 복구된다.
- [ ] 결과가 없으면 시간 30분 늘리기, 조건 해제, 다른 장소 검색을 제공한다.
- [ ] 시간 확대가 최대 24시간을 넘지 않는다.

### 결과와 경유지

- [ ] 지도에 출발·목적지·경로·붉은 후보 영역이 보인다.
- [ ] 음식점·카페·관광지 등 후보 핀 아이콘이 구분된다.
- [ ] 핀 또는 카드로 후보를 선택·해제할 수 있다.
- [ ] 선택 핀에 빨간색과 경유 순서 배지가 보인다.
- [ ] 선택 순서가 출발지→목적지 방향으로 다시 정렬된다.
- [ ] 경유지 5개를 넘겨 선택할 수 없다.
- [ ] 안전 여유가 부족해지는 후보 추가가 차단된다.
- [ ] 예상 총시간과 남는 여유가 선택에 따라 갱신된다.
- [ ] 카카오맵 실행 시 출발지, 선택 경유지, 최종 목적지가 모두 전달된다.
- [ ] 카카오맵 미설치 시 웹 또는 설치 경로로 안전하게 이동한다.

### 상세·둘러보기·저장

- [ ] 상세에 장소명, 분류, 시간, 운영상태, 태그가 표시된다.
- [ ] 운영정보가 없으면 `운영시간 확인 필요`를 표시한다.
- [ ] 장소 저장·해제가 즉시 반영된다.
- [ ] 앱 재실행 후 저장 장소가 남아 있다.
- [ ] 둘러보기에서 100개 단위 추가 로딩이 동작한다.
- [ ] 대표 이미지가 없거나 실패해도 기본 이미지가 보인다.
- [ ] 긴 장소명은 한 줄 말줄임 처리된다.
- [ ] 태그가 넘치면 `+ n`으로 축약된다.
- [ ] 저장 해제 Snackbar의 되돌리기가 동작한다.

### 설정

- [ ] 위치 권한 상태가 실제 설정과 맞는다.
- [ ] 카카오맵 설치 상태·실행·설치 링크가 동작한다.

## 4. 백엔드 스모크 테스트

Preview 배포 후 운영 승격 전에 확인합니다. 실제 키나 응답 전체를 로그에 남기지 않습니다.

- [ ] `GET /api/health`가 200이고 필요한 연동 설정이 true다.
- [ ] `GET /api/places?page=1&pageSize=10`이 데이터와 pagination을 반환한다.
- [ ] `GET /api/places/{contentId}`가 존재·부재를 구분한다.
- [ ] `GET /api/geocode?q=강릉역`이 좌표와 주소를 반환한다.
- [ ] `GET /api/region`이 강원도 안·밖 좌표를 구분한다.
- [ ] 유효한 `POST /api/recommendations`가 추천과 meta를 반환한다.
- [ ] 잘못된 좌표·시간·카테고리는 400으로 거부된다.
- [ ] 차량 응답의 provider와 경로가 올바르다.
- [ ] 도보 응답에 추정값 경고가 포함된다.
- [ ] 영업 종료 장소가 추천에서 제외된다.
- [ ] 운영정보 미확인 장소는 `UNKNOWN`으로 남는다.
- [ ] Cron은 올바른 Bearer secret 없이는 거부된다.
- [ ] Cron 성공 후 `sync_state`가 갱신된다.

## 5. 알려진 문제

### P0 — 기준선과 검증

#### Android 단위 테스트 실행 실패

- 증상: 모든 테스트 클래스에서 `ClassNotFoundException`.
- 확인된 사실: 테스트 `.class`와 테스트 소스 컴파일은 존재한다.
- 영향: 회귀 테스트 통과를 주장할 수 없다.
- 다음 조치: 영문 경로의 새 clone에서 재현 후 Gradle worker classpath를 수정한다.

#### 배포 APK가 최신 소스보다 오래됨

- 배포 APK는 `2026-08-13 22:00:05` 빌드다.
- 후보 핀 아이콘 소스는 같은 날 `22:14:57`에 수정됐다.
- 통합 저장소에서는 2026-08-16 최신 소스로 디버그 APK 빌드까지 성공했다.
- 로컬 검증 APK: 54,829,565바이트, SHA-256 `823A92D2118EC7F42FA9382DF1477527A593A0345A17B3EFECDA5DDB9705C5A2`.
- 영향: 운영 다운로드 APK로 확인한 UI와 Git 소스가 다르며, 로컬 검증 APK도 실기기 회귀를 거치지 않았다.
- 다음 조치: 버전을 `0.12.4`/`versionCode 25` 이상으로 올리고 실기기 스모크 테스트 후 새 파일로 배포한다.

### P1 — 추천 정확도와 주요 UX

#### 시간 입력의 의미가 미확정

- 현재 API는 전체 사용 가능 시간을 `deadlineMinutes`로 받는다.
- 논의 중인 문구는 기본 이동시간을 제외한 순수 여유시간처럼 읽힌다.
- 문구와 계산을 함께 결정해야 한다.

#### 복수 경유지 시간은 합산 예상

- 각 단일 후보의 우회·머무름을 더할 뿐 전체 경로를 재조회하지 않는다.
- 후보 간 중복 구간과 교통 상황을 반영하지 않는다.
- UI는 계속 `예상`으로 표시해야 한다.

#### 경유지 순서는 도로 최적화가 아님

- 출발지→목적지 직선 벡터 투영 순서다.
- 산악지형과 실제 도로 우회 때문에 최적 순서와 다를 수 있다.

#### 붉은 후보 영역은 실제 도달 가능 영역이 아님

- 한 추천 경로를 기준으로 여러 원을 겹친 시각 표현이다.
- `100% 가능 범위`처럼 설명하면 안 된다.

#### 도보 시간은 직선거리 추정

- 실제 보행로, 횡단보도, 고도와 통행 제한을 반영하지 않는다.
- 결과에 경고를 유지한다.

#### 카페 데이터 공백 가능성

- TourAPI 음식점이 `RESTAURANT`로 정규화돼 `CAFE` 필터가 충분한 결과를 내지 못할 수 있다.

#### 장소 둘러보기 검색 범위

- 검색·필터는 현재까지 내려받은 페이지에만 적용된다.
- 서버 전체 검색이 아니다.

#### 상세 동기화 속도

- 기본 배치 10개/일이면 장소 1,000개의 한 주기에 약 100일이 걸린다.

#### 공개 API 요청 제한 없음

- 검색·지역·추천 API에 앱 인증 또는 명시적 Rate Limit이 없다.
- 추천 한 번이 Kakao 경로 호출 최대 20회를 유발할 수 있다.

### P2 — 유지보수와 스토어

#### 단일 대형 UI 파일

- `TteumsaeApp.kt` 약 4,179줄에 화면·상태·지도·딥링크가 집중돼 있다.
- 충돌과 회귀 위험이 높다.

#### 프로세스 복원 불일치

- 화면 enum은 복원돼도 좌표·추천·선택 데이터 일부는 복원되지 않는다.

#### 정책 URL 없음

- 개인정보처리방침과 위치기반서비스 약관 상수가 비어 있다.

#### 릴리스 체인 없음

- signingConfig, 릴리스 키 전달 절차, AAB, Play App Signing과 CI가 없다.

#### 제거된 TourAPI 장소 정리 없음

- 원본에서 사라진 장소를 `is_active=false`로 바꾸는 정리 작업이 없다.

#### 반려동물 태그 신뢰도

- 상세 객체 존재만으로 태그가 붙을 가능성이 있어 실제 허용 필드 검증이 필요하다.
