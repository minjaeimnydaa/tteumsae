## 1. 먼저 확인할 버전

## 2. 사용자가 확인할 변화

1. **도로명·지번 주소 검색:** 장소명뿐 아니라 주소 자체를 찾아 선택할 수 있다. 주소와 장소
   결과를 구분하며 도로명·지번 정보를 함께 보여준다.
2. **지도와 목록의 연결:** 결과 화면에서 지도를 유지한 채 하나의 시트를 접힘·중간·펼침으로
   전환한다. 지도/목록 왕복 자체로 전체 경로를 강제로 다시 맞추거나 읽던 목록을 초기화하지 않는다.
3. **선택 행동의 연속성:** 같은 카드의 같은 버튼 영역에서 선택·선택됨을 표시하고 상세보기와
   구분한다. 지도 핀 선택은 해당 카드를 보여주며, 묶음 탐색 자체로 기존 선택·알림을 해제하지 않는다.

디자인 분위기, 차량 이동·경유지 한 곳, 선택 출발지 기준 재계산, 관광 상세 정보, 기기 저장,
선택 로그인·알림이라는 범위는 유지한다. 기기 GPS 취득이나 위치 권한 요청을 추가한 버전이 아니다.
**상세 왕복에서는 시트·목록 상태를 복원하지만, MapView가 재생성되므로 카메라 위치·확대 배율은
보존하지 않는다.** 결과 화면 안의 지도/목록 왕복과 이 제한을 구분한다.
