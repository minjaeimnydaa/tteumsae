## 3. 과거 APK 감사와 현재 출시 변경의 구분

### 수동 출시본에 반영한 범위 — 최종 code33 확인

- 기본 빌드는 `manual`, 자동 위치 공급자와 권한은 별도 `automatic` 빌드로 분리한다.
- 수동 빌드에서는 현재 위치 버튼·위치 권한 요청·자동 출발지 채우기·GPS 역지오코딩을 사용하지 않는다.
- 출발지와 목적지는 사용자가 장소 검색 결과에서 선택한다. 선택 장소의 좌표를 서버에 보내
  경유지·차량 경로를 계산한다. 따라서 **모든 좌표의 서버 전송이 없는 앱**으로 설명하지 않는다.
- `현재 교통으로 다시 확인`은 선택한 출발점과 기존 목적지·도착 마감을 기준으로 재계산한다.
  사용자가 실제로 이동한 위치를 새로 취득하거나 추적하는 기능이 아니다.
- 이전 자동 위치 버전의 입력·알림 좌표가 수동 모드로 복원되지 않게 모드 경계를 적용하고
  단위 회귀를 통과했다. 기존 GPS 데이터 보존 업데이트의 실증은 하지 않았다.
  저장 장소와 선택 로그인 등 나머지 기능은 유지한다.
- 제출 소개·스크린샷·정책·검증팀 메모는 최종 수동 APK와 일치시킨다.

### 0.12.9 과거 기준선의 권한·광고·로그인 감사

- `android/app/build.gradle.kts` 직접 의존성과 Android 소스에서 AdMob, 광고 ID,
  AppLovin, Unity Ads, Meta Audience Network, 결제 SDK, Firebase Analytics 사용을 찾지 못했다.
- 폰에서 읽어온 0.12.9 APK의 실제 권한은 `INTERNET`, `ACCESS_COARSE_LOCATION`,
  `ACCESS_FINE_LOCATION`, `POST_NOTIFICATIONS`, `RECEIVE_BOOT_COMPLETED` 및 AndroidX의
  앱 내부 receiver 보호용 권한이다. `AD_ID`, 결제, 연락처·카메라·마이크·광범위한 저장소,
  백그라운드 위치·정확한 알람 권한은 포함되지 않았다.
- 현재 위치는 사용자가 요청할 때 가져오고 요청 종료/취소 때 위치 업데이트를 해제한다.
  위치 거부 시 출발지를 직접 검색할 수 있다. 알림은 별도 선택 기능이다.
- 시작 화면은 HOME이며 인증 상태로 검색·추천·상세를 차단하지 않는다. 로그인은 설정의
  계정 영역에서 선택한다. 장소 저장은 `RoomSavedPlacesRepository.toggleGuest`로 처리한다.
- 앱이 직접 제공하는 저장 장소의 계정 간·기기 간 동기화는 없다. 프로필만 선택 로그인
  이후 Supabase에 저장하며 계정 삭제 기능이 존재한다. 실제 계정 삭제는 점검하지 않았다.

## 6. 검증팀 참고사항·테스트 절차 초안

핵심 기능은 로그인 없이 이용할 수 있어 공용 테스트 계정이 필요하지 않습니다.
이 제출 버전은 기기 현재 위치 취득과 위치 권한 요청 없이 출발지를 직접 검색·선택합니다.
사용자가 선택한 장소 좌표로 서버에서 경로를 계산합니다. 실제 차량 운행은 필요하지 않습니다.

1. 틈새를 실행하고 홈 지도와 안내를 확인합니다.
2. 목적지 검색으로 들어가 출발지 `강릉역`, 목적지 `경포대`를 검색해 각각 결과를 선택합니다.
3. 도착 시각은 **검사하는 현재 시각보다 약 2시간 이후**로 설정합니다. 관심 필터는 선택하지 않아도 됩니다.
4. 틈새 찾기를 눌러 결과를 확인합니다. 운영시간과 현재 시각에 따라 후보 수·장소는 달라집니다.
   무결과인 경우 입력을 수정하거나 목적지 직행을 선택할 수 있습니다.
5. 후보 한 곳을 선택해 체류·출발 안내를 확인하고 지도/목록 왕복 및 상세 보기→뒤로를 확인합니다.
6. 카카오맵 길 안내를 눌러 출발지·경유지 한 곳·목적지 전달을 확인합니다. 미선택 시 직행 경로를 확인할 수 있습니다.
7. 장소 탐색에서 장소를 저장·해제하고, 설정에서 개인정보처리방침과 문의 방법을 확인합니다.
8. 선택 로그인까지 검사하려면 설정→계정에서 카카오 또는 Google의 검증 담당자 소유 계정으로 로그인합니다.
   로그인은 추천 필수 단계가 아니며 개인정보가 포함된 실제 운영자 계정을 테스트 계정으로 제공하지 않습니다.
9. 재확인을 눌러 선택한 출발지·목적지 기준의 결과 갱신을 확인합니다. 기기 현재 위치로
   출발지가 자동 변경되지 않는 것이 이 버전의 정상 동작입니다.

최종 release 빌드에서 위 절차를 다시 실행한 뒤 검증 메모로 사용한다. 이 절차 자체가 통과 기록은 아니다.
