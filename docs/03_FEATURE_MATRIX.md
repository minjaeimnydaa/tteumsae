## 2026-10-16 GUI·사용성 개선 — 기본 수동 모드 빌드 검증 통과

`codex/gui-design-system`은 [공통 스타일 규칙](30_GUI_DESIGN_SYSTEM.md)의 글자,
padding과 모서리를 Android UI에 연결하고 [추가 감사](31_GUI_FOLLOWUP_AUDIT.md)의
열 가지 개선을 10월 15일 구현했다. **0.14.0 / code35** 기본 수동 모드는 10월 16일
**270/270 / 58 suites**, lint 오류 **0**·경고 **52**, debug 빌드를 통과했다. 자동 위치
보존 모드도 **270/270 / 58 suites**와 debug 빌드를 통과했으며 새 실기기 통과 기록은 없다. 아래 과거 검증 기록을 이번
변경의 통과 증거로 사용하지 않는다. 확정 결과는 [QA 기록](08_QA_AND_KNOWN_ISSUES.md)을 따른다.

## 0.12.9 당시 UI 변경 (2026-09-11 이력)

장소 탐색은 상단 스크롤 안내와 하단 로딩·더 보기·끝 상태를 제공하며 개수는 현재 표시 중인
장소 수다. 결과는 `목록 보기 ↔ 지도 보기`의 명시적 전환으로 바뀌었고 카드 안의 경로 버튼과
드래그 시트 전환은 폐기했다. 선택 경유지는 두 보기에서 공유한다. 자동 검증은 통과했으며
새 조작의 실기기 검증은 08 QA의 0.12.9 기록을 따른다.

아래 표는 Gate 2 기능 기준선에 이번 변경의 현재 동작을 반영한다. 과거 배포본의
자동 검증과 새 코드의 검증을 구분하며, 향후 아이디어는
[다음 버전 계획](09_NEXT_VERSION_PLAN.md)에만 기록한다.

## 2026-09-11 — UX 감사 후 1차 개선

- 비지원 목적지 안내를 검색 입력 바로 아래와 실제로 누른 결과 행에 표시한다.
- 결과 뒤로·재조회는 시트 밖 Scaffold 상단에 배치하고 시트 높이는 상·하단을 제외한 가용 높이로 제한한다.
- 후보의 이름·시간·상세 행동을 분리하고 운영 미확인 상태를 선택 전에 표시한다.
- 계산 경과 문구는 30초마다 갱신한다. 체류시간 자체를 임의 차감하거나 자동 재조회하지 않는다.
- 주변 주차장은 별도 `ui/route/NearbyParkingSection.kt`에서 1곳 우선·추가 펼침으로 제공한다.
  실시간 빈자리 미제공과 방문객 이용 확인을 안내하고 거주자우선 명칭은 이용 가능 확정 없이 주의 문구만 붙인다.
- 사진 없는 상세 영역을 132dp에서 64dp로 축소하고 결과·상세 길 안내 문구를 통일한다.
- 탐색 검색은 `장소명·주소 검색`, 기본 정렬은 `기본순`으로 명확히 한다.
- 큰 글자 결과 상단 제목은 `경유지 선택`으로 축약한다. 선택 카드의 `전체 경로`는
  선택 상태를 유지하며 시트를 낮추고, `목록 펼치기`로 원래 목록 높이로 복귀한다.
- 코드·자동 검증 완료와 실기기 검증 완료는 구분한다. 이번 수정의 화면 검증은 QA 기록을 따른다.
