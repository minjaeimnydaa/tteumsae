## 4. 그대로 살릴 내용

- 관광지를 찾고 우회·체류시간까지 직접 판단해야 하는 번거로움이라는 문제 정의.
- 강원 여행의 자투리 시간을 관광 경험으로 활용한다는 지역 특화 방향.
- 출발지·목적지·도착 시각을 한 화면에서 설정한다는 단순한 사용 흐름.
- 추가 이동시간·머물 수 있는 시간·운영 정보를 함께 비교한다는 핵심 가치.
- 경유지 한 곳 선택 후 카카오맵으로 연결하고, 관심 장소를 저장한다는 기능 설명.
- 지역 관광 데이터 확대와 협력·타 지역 확장을 미래 계획으로 제시하는 방향.

| `목적지까지 안내하는 경유지 길찾기` | 앱 내부 턴바이턴 내비게이션 아님 | `선택 경로를 확인하고 카카오맵 길 안내로 연결` |
| `출발 권장 시간 전에 알림` | 선택 알림이며 기기 절전 등에 따라 지연 가능 | `출발 시각 확인을 돕는 선택 알림. 기기 설정에 따라 늦어질 수 있음` |

자동 위치 버전은 필요한 절차와 검증을 갖춘 **새 버전**으로 배포하는 계획이다.
신고 이력·필증이 없는 상태를 `신고 진행 중`이나 `심사 중`으로 바꾸어 쓰지 않는다.
수동 버전의 법적 면제 또는 원스토어 승인도 확정된 사실로 표현하지 않는다.

## 6. 주요 원문 근거

문구는 사용자 제공 Keynote에서 읽은 원문이며 현재 기능 사실로 승인한 문구가 아니다.

### 선정 이유 (`Index/Tables/DataList-700-2.iwa`, 객체 700)

> 여행 중 발생하는 이동 시간과 자투리 시간은 충분히 활용되지 못하고 있으며, 여행자는 짧은 시간 안에 들를 수 있는 장소를 직접 검색하고 판단해야 하는 불편을 겪고 있습니다.
> 특히 관광자원이 넓게 분산된 강원도에서는 현재 위치, 이동 경로, 남은 시간에 맞는 신뢰도 높은 관광정보를 빠르게 제공하는 서비스가 필요합니다.
> 이에 ‘틈새’는 공공 관광데이터 기반의 공식·검증형 관광 스팟을 추천해, 비어 있는 시간을 여행 경험으로 전환하고 지역 관광 활성화에 기여하고자 합니다

### 핵심기능 (`Index/Tables/DataList-746-2.iwa`, 객체 17373)

> 출발지, 목적지, 현재 위치, 도착 시간을 한 번에 설정하는 여행 경로 설정 기능
> 도착까지 남은 시간과 선택한 장소 유형을 반영해 방문 장소를 추천하는 여유 시간 맞춤 추천 기능
> 추천 장소별 추가 이동 시간과 방문 가능 여부를 비교해 선택하는 추천 장소 비교·선택 기능
> 선택한 장소를 경유지로 추가해 목적지까지 안내하는 경유지 길찾기 기능

### 지역 특화 (`Index/Tables/DataList-800-2.iwa`, 객체 800)

> 강원특별자치도 내 여행자의 출발지와 목적지, 도착 예정 시간, 선호 관광 유형을 바탕으로 이동 경로 주변의 공식 관광지를 추천하는 서비스입니다.
> 추천 장소별 추가 이동 시간, 운영시간, 주차 가능 여부, 체류 가능 시간을 제공하고, 선택한 장소를 경유지로 설정해 카카오맵 길찾기까지 연결합니다.

### 카카오맵 활용 (`Index/Tables/DataList-930-2.iwa`, 객체 930)

> 서비스 내 지도 화면과 이동 경로를 표시하고, 추천 관광지를 경유지로 포함한 길찾기 정보를 외부 지도·내비게이션 서비스로 연동하기 위해 활용했습니다.

### 발전계획 (`Index/Tables/DataList-957-2.iwa`, 객체 957)

> 향후 강원특별자치도 내 관광·교통·행사 데이터를 확대 연계해 추천 범위를 넓히고, 이용자의 이동 패턴과 선호도를 반영한 개인 맞춤형 추천 기능을 고도화할 계획입니다.
> 실시간 교통 상황과 관광지 운영 여부를 반영해 추천 정확도를 높이고, 방문 이력과 사용자 피드백을 활용해 추천 품질을 개선할 예정입니다.
> 또한 지역별 관광기관 및 지자체와의 협력을 통해 지역 관광 콘텐츠를 지속적으로 발굴하고, 다른 지역으로 서비스를 확장할 계획입니다.

## 7. 기존 작성 초안과의 연결

- `docs/19_CONTEST_FUNCTIONS_DRAFT.md` 2~4절은 팀원의 문제 정의·시간 중심 차별성을 유지하면서
  현재 수동 입력·한 곳 선택·외부 카카오맵 연결을 구체화한다.
- 19번 문서 5절의 실제 API 활용 표로 Keynote의 미작성 TourAPI 표와 기타 데이터 표를 채울 수 있다.
- 19번 문서 6절로 현재 기능과 향후 자동 위치·개인화 계획을 분리한다.
- 19번 문서 7절에 따라 최종 APK 캡처를 촬영해 대표·상세 이미지와 기능별 흐름도를 채운다.
- 팀명 `자투리`는 이번 파일에서 근거를 확보했다. 사용자 최종 신청 정보 확인 전까지 확정 사실로 승격하지 않는다.

최종 산출물은 공식 양식의 구조와 실제 제출 APK를 함께 대조해야 한다. 본 검토 문서는
원본 초안을 대체하거나 원스토어·공모전 제출 완료를 나타내지 않는다.
