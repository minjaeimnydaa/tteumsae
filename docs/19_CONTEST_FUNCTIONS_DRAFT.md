## 2. 서비스 소개

### 서비스명

틈새

### 한 문장 소개

도착해야 할 시각은 지키고 싶은데 시간이 조금 남았다면, 강원 여행길에 들를 한 곳을 찾아보세요.

### 해결하려는 문제

여행 중 체크인, 식당 예약, 공연이나 약속까지 애매한 여유가 생겨도 새로운 장소에 들렀다가
늦을까 걱정되곤 합니다. 장소를 찾은 다음 우회 이동시간과 머무는 시간, 다시 출발할 시각까지
각각 계산하는 과정도 번거롭습니다.

틈새는 사용자가 직접 선택한 출발지·목적지와 도착 마감을 함께 고려해 차량 경로 주변의
경유지 한 곳을 비교하도록 돕습니다. 단순히 가까운 장소를 나열하는 대신 추가 이동시간,
이동 기준 최대 체류시간과 출발 권장시각을 보여 주어 여행자의 판단을 지원합니다.

### 주요 이용자와 사용 상황

- 강원 지역 목적지로 이동하는 여행자와 동승자.
- 체크인·예약·공연·약속 등 도착 마감 전 남는 시간을 활용하려는 사람.
- 출발 전에 역·숙소·관광지 등 원하는 장소를 출발점으로 정해 경유 가능성을 확인하려는 사람.

앱은 출발 전 정차 상태 또는 동승 중에 조작하는 상황을 전제로 합니다.

## 3. 핵심 기능과 사용자 흐름

기본 흐름: **홈 → 출발지·목적지·도착 시각 선택 → 추천 계산 → 목록·지도 비교 → 장소 상세 → 카카오맵 연결**

| 화면·기능 | 이용 방법 | 사용자에게 주는 정보·편의 |
|---|---|---|
| 홈 | 목적지 검색에서 경로 입력 시작 | 여행 중 들를 한 곳을 찾는 핵심 흐름에 바로 진입 |
| 경로 입력 | 출발지와 목적지를 검색 결과에서 각각 선택 | 기기 현재 위치에 의존하지 않고 원하는 여행 구간 설정 |
| 도착 마감 | 같은 화면에서 시·분을 선택 | 상대적인 여유시간을 따로 계산할 필요 없이 도착해야 할 시각 입력 |
| 선택 관심 필터 | 식사·카페·관광 등 원하는 관심 범위 선택 | 기본값으로 바로 검색하거나 필요할 때만 후보 좁히기 |
| 추천 결과 목록 | 추가 이동시간·최대 체류시간·운영 정보 비교 | 장소에 들렀을 때의 시간 부담 판단 |
| 결과 지도 | 장소 종류 아이콘·묶음 핀·경로 확인 | 후보의 위치 관계와 선택한 경로를 시각적으로 비교 |
| 한 곳 선택 | 후보 선택·교체·해제, 선택 장소 상세 열기 | 다중 일정 편집 없이 경유지 한 곳에 집중 |
| 상세 정보 | 사진·주소·운영 및 방문 보조 정보 확인 | 확보된 공식 데이터를 바탕으로 방문 전 확인할 내용 탐색 |
| 교통 재확인 | 선택한 출발지·목적지·도착 마감으로 다시 계산 | 시간이 지난 추천을 그대로 사용하는 위험 줄이기 |
| 출발 알림 | 원하는 경우 알림 켜기 | 선택한 경유지에서 출발할 시각을 잊지 않도록 보조 |
| 외부 길 안내 | 카카오맵 연결 | 선택한 경로 확인 후 익숙한 외부 지도에서 안내 이어가기 |
| 탐색·저장 | 장소 둘러보기, 저장·해제 | 관심 장소를 기기에 저장해 다시 찾아보기 |
| 선택 로그인 | 설정에서 카카오·Google 계정으로 로그인 | 핵심 기능과 분리된 계정·프로필 관리 |

검색·추천·상세·장소 저장은 로그인 없이 이용할 수 있습니다. 장소 저장은 기기 로컬 저장이며,
현재 앱 자체의 계정 간·기기 간 저장 장소 동기화는 제공하지 않습니다.

## 4. 시간과 경로를 함께 고려하는 방식

사용자는 출발지, 목적지와 도착해야 할 절대시각을 입력합니다. 서버는 계산 시점의 남은 시간과
차량 경로를 이용해 후보를 비교합니다. 안전여유 10분과 최소 체류 15분은 서비스가 관리합니다.

- 목적지로 바로 가는 경로와 경유지를 들르는 경로를 비교해 추가 이동시간을 안내합니다.
- 전체 경유 이동시간과 안전여유를 제외한 이동 기준 최대 체류시간을 계산합니다.
- 확인 가능한 운영시간·입장 마감이 있으면 방문 가능 구간을 추가로 제한합니다.
- 시간이 부족하거나 확인된 운영 조건상 방문하기 어려운 후보는 제외합니다.
- 불명확한 영업정보를 `영업 중`으로 확정하지 않고 확인 필요 상태로 안내합니다.
- 경유하지 않기로 결정하면 목적지로 바로 가는 선택도 제공합니다.

결과는 **선택한 출발지와 계산 당시 정보에 따른 예상**입니다. 교통 재확인을 눌러도 사용자의
물리적인 현재 위치를 새로 취득하지 않습니다. 실제 출발 장소가 달라졌다면 출발지를 수정해야 합니다.
주차·도보·대기·현장 상황을 모두 알 수 없으므로 정시 도착이나 실제 영업을 보장하지 않습니다.

## 5. 관광·공공 데이터 활용

API 수보다 해당 정보가 이용자의 어떤 판단을 돕는지 중심으로 설명합니다.

| 데이터·연계 | 실제 활용 내용 | 이용자의 판단에 도움이 되는 지점 |
|---|---|---|
| 한국관광공사 국문 관광정보 `KorService2` | 장소 목록·공통·소개·사진·반복 안내·반려동물 관련 상세 정보의 확보 항목 표시 | 방문할 장소의 성격, 운영시간, 주소, 이용 조건 확인 |
| 관광지 집중률 예측 | 이름이 정확하고 유일하게 일치하는 강릉 장소에 연결한 날짜별 상대 예측 | 방문일의 혼잡 가능성을 참고. 실시간 인원으로 표현하지 않음 |
| 무장애 여행정보 `KorWithService2` | 기존 관광정보 content ID와 일치하는 장소의 접근성 정보 표시 | 출입구·접근로 등 확보된 편의 정보를 미리 확인 |
| 기상청 단기예보 | 적용되는 야외 장소의 도착 무렵 격자 예보 | 강수·기온 등을 야외 방문 판단의 보조 정보로 활용 |
| 전국주차장정보표준데이터 | 확보된 강릉 공영주차장 중 장소 반경 1km 안 가까운 최대 3곳 | 주변 공영주차장 선택을 돕되 직선거리와 실시간 빈자리 정보의 차이를 안내 |
| 카카오 지도·Local·차량 경로 | 지도 표시, 장소 검색, 선택 장소 지역 확인, 차량 이동시간·경로, 외부 지도 연결 | 관광 정보에 실제 이동 부담을 결합 |

정보 종류와 보강 범위는 장소마다 다릅니다. 없는 방문정보를 더미 문장으로 채우지 않고,
사진·운영·주차·접근성·날씨 등이 확보된 경우에 해당 내용을 제공합니다.
날씨와 혼잡 예측은 상세의 보조 정보이며 현재 추천 순위나 방문 가능 계산의 판단값으로 사용하지 않습니다.

## 6. 이번 제출 버전과 향후 자동 위치 버전

### 이번 제출 버전

출발지와 목적지는 **장소 검색 결과에서 직접 선택**합니다. 기기 GPS 권한을 요청하거나
기기 현재 위치를 가져오지 않습니다. 선택한 장소의 좌표는 경로·추천 계산을 위해 서버와
지도 제공자에 전달합니다. 따라서 `위치 좌표를 일절 처리하지 않는다`고 설명하지 않습니다.

현재 위치 버튼과 위치 권한 설정을 노출하지 않으며, 결과에 `선택한 출발지 기준`임을 안내합니다.
운영 서버 연결, 관광정보 상세, 저장, 선택 로그인과 외부 카카오맵 연결은 같은 핵심 흐름으로 유지합니다.

### 향후 확장 방향

기존 자동 위치 기능은 소스 구조상 별도 빌드로 보존합니다. 필요한 신고·정책·동의 및 검증을
갖춘 뒤 **새 앱 버전으로 배포**하는 방향입니다. 이번 제출 APK를 원격 설정으로 자동 위치형으로
전환하지 않습니다. 이 항목은 향후 계획이며 현재 제출 기능으로 시연하거나 성과에 포함하지 않습니다.
