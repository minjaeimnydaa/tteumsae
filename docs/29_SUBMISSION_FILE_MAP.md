## 4. API 키를 안전하게 제출하는 순서

1. 팀이 [공식 안내](https://lowly-polyanthus-1fb.notion.site/2026-36b5dce406e380e0a3d1f80525667a11)에서
   실제 제출 사이트를 열고 기존 접수 계정으로 로그인한다. 메일이나 채팅으로 온 임의 키 요청에 응하지 않는다.
2. 키 소유자가 [관광공사 API 인증키 안내](https://drive.google.com/file/d/1iAy4zLbWT4gWbc7PkW2mujdQBFD-2-BC/view?usp=sharing)와
   실제 포털 요구를 확인한다. 이전 확인 기록은 **사용 API의 신청자별 인코딩·디코딩 인증키 일체**를 요구한다.
   우리 서버의 환경 파일 전체나 Kakao·Vercel·Supabase·서명키까지 제출하라는 뜻이 아니다.
3. 소유자가 자기 계정에서 확인한 값을 승인된 공식 필드에 직접 입력한다. 값을 이 채팅, Git,
   기능설명서 PDF/PPTX, 권리 자료, 공개 페이지, 팀 ZIP에 복사하지 않는다. 입력 후 키가 보이는 캡처도 공유하지 않는다.
4. 검토 기록에는 ‘소유자 대조 완료 / 공식 필드 입력 완료’ 여부만 남긴다. 인증키 확인·제출을
   대신 수행한 것으로 기록하거나 본인 신청 확인만으로 실제 키 대조까지 완료됐다고 쓰지 않는다.

APK에는 공개 클라이언트용 Kakao native 앱 설정이 포함될 수 있다. 따라서 공유 검사를
‘모든 API 키가 APK에 없다’고 표현하지 않는다. **TourAPI·서버 비밀키·서명 비밀값은 공유 대상에서 제외**한다.
