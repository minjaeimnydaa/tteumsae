## 2026-08-16 — 단일 기준 저장소

상태: 확정

결정:

- Android, 백엔드, 다운로드 페이지와 문서를 `minjaeimnydaa/tteumsae` 한 저장소에서 관리한다.
- 최상위 폴더는 `android/`, `backend/`, `download/`, `design/`, `docs/`를 사용한다.
- 다른 작업 폴더와 과거 ZIP은 기준 원본으로 사용하지 않는다.

이유:

- 기존 Git 문서는 `0.10.1`, 실제 Android는 `0.12.3`으로 분리돼 있었다.
- 백엔드도 별도 저장소의 미커밋 변경과 인수 스냅샷이 갈라져 있었다.

영향:

- 기능 변경과 문서를 같은 커밋에서 검토할 수 있다.
- 배포 링크는 기록하되 APK 바이너리는 Git에 넣지 않는다.

## 2026-08-16 — 경유지 선택 표시 역할

상태: 확정

결정:

- 후보 카드 순서는 `장소 1/20`처럼 표시한다.
- 선택 현황은 `경유지 2/5`처럼 별도로 표시한다.
- 지도 선택 핀에는 실제 방문 순서 `1`, `2`, `3`을 표시한다.
- 카카오맵 전달 경유지는 최대 5개다.

이유:

- `1/20`만 표시하면 후보 위치와 선택 개수를 혼동할 수 있다.

영향:

- 최신 결과 화면 상단 카드에는 경유지 배지가 필요하다.

## 2026-08-13 — 장소 후보 핀

상태: 확정

결정:

- 기본 후보 핀은 파란색 장소 유형 아이콘을 사용한다.
- 선택 후보는 브랜드 빨간색 테두리와 경유 순서 배지를 사용한다.
- 별점 데이터는 현재 제공하지 않으므로 지도 핀에 가짜 별점을 표시하지 않는다.

이유:

- TourAPI 카테고리는 이미 있어 추가 API 없이 장소 유형을 구분할 수 있다.
- 실제 데이터가 없는 평점 표시는 신뢰를 해친다.

## 2026-08-13 — 복수 경유지 시간 표기

상태: 확정

결정:

- 앱의 복수 경유지 총시간과 남는 시간은 `예상`으로 취급한다.
- 최종 실제 경로와 시간은 카카오맵이 다시 계산한다.

이유:

- 현재 Android는 단일 후보별 우회·머무름을 합산한다.
- 전체 경유지를 Kakao Mobility로 재조회하지 않는다.

다시 검토할 조건:

- 백엔드에 복수 경유지 통합 경로 API가 구현될 때.

## 2026-08-13 — 브랜드 색상

상태: 확정

결정:

- 은은한 그림자와 비활성 파생색은 Primary의 투명도 또는 명시된 토큰을 사용한다.

영향:

## 2026-08-03 — 이동 탐색의 이동수단

상태: 확정

결정:

- `경로 따라 갈 장소`는 자동차를 전제로 한다.
- `근처에서 갈 장소`만 도보와 자동차를 선택한다.

이유:

- 이동 탐색은 카카오맵 자동차 경유지 안내로 연결한다.
- Kakao Mobility 일반 길찾기는 보행 경로 시간을 제공하지 않는다.

## 2026-08-03 — 서버 키 경계

결정:

영향:
