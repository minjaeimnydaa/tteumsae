# 제품 범위와 용어

## 1. 서비스 정의

> 강원도 여행 중 대중교통 대기, 출발 전후 또는 장거리 이동 사이에 생긴 남는 시간 안에서 들를 수 있는 장소를 추천하는 서비스

일반 지도 앱은 거리나 인기도 중심으로 장소를 보여줍니다. 틈새는 출발지에서 장소까지 이동하고, 장소에 머문 뒤, 목적지에 늦지 않게 도착할 수 있는지를 우선합니다.

현재 앱은 강원도 장소만 추천합니다. 출발지는 강원도 밖일 수 있지만 이동 탐색의 최종 목적지는 강원도여야 하며, 근처 탐색의 기준 위치도 강원도 안이어야 합니다.

## 2. 핵심 사용자 문제

- 버스·기차 또는 약속까지 30분~수 시간 남았지만 무엇을 할지 결정하기 어렵다.
- 관광지 사이 거리가 멀어 지도상의 가까운 장소도 실제로 다녀오기 어려울 수 있다.
- 장소 체류시간과 왕복·우회 시간을 따로 계산하기 번거롭다.
- 시간이 부족하거나 문을 닫은 장소를 추천받으면 여행 일정이 깨진다.
- 현재 배가 부르거나 실내 활동이 필요한 상황처럼 즉시 달라지는 의도가 있다.

## 3. 탐색 모드

### 경로 따라 갈 장소 (`ON_THE_WAY`)

출발지에서 강원도 목적지로 자동차로 이동하는 길에 들를 장소를 추천합니다.

- 출발지는 GPS 현재 위치 또는 검색 장소입니다.
- 목적지는 사용자가 검색합니다.
- 이동수단은 현재 자동차로 고정합니다.
- 결과에서 후보를 최대 5개까지 경유지로 선택할 수 있습니다.
- 최종 안내는 카카오맵 자동차 경로로 넘깁니다.
- 카카오맵이 최종 실제 경로와 소요시간을 다시 계산합니다.

### 근처에서 갈 장소 (`NEARBY`)

현재 위치 또는 선택한 강원도 장소를 기준으로, 정해진 시간 안에 방문하고 돌아올 수 있는 장소를 추천합니다.

- 출발지와 도착지를 같은 좌표로 서버에 전달해 왕복을 표현합니다.
- 도보 또는 자동차를 선택할 수 있습니다.
- 도보 시간은 현재 직선거리 기반 추정입니다.
- 강원도 밖 위치에서는 추천을 시작할 수 없습니다.
- 선택한 장소는 카카오맵 단일 목적지 안내로 연결합니다.

## 4. 시간 관련 용어

### 입력 시간 (`deadlineMinutes`)

현재 구현에서 사용자가 입력하는 시간은 추천 여정 전체에 사용할 수 있는 시간입니다.

```text
출발지 → 장소 이동
+ 추천 머무름
+ 장소 → 목적지 이동
≤ 입력 시간 - 안전 여유
```

현재 경로 모드 문구는 `목적지 도착까지 얼마나 시간이 남았나요?`입니다. 최근 디자인에서 논의한 `기본 이동시간을 제외한 순수 여유시간`과는 계산 의미가 다릅니다. 다음 버전에서 문구만 바꾸면 안 되며 아래 중 하나를 제품 결정으로 선택해야 합니다.

1. 현재처럼 전체 남은 시간을 입력받는다.
2. 카카오 기본 경로 시간을 먼저 계산하고, 사용자는 순수 여유시간만 입력한다.

결정 전까지 API의 `deadlineMinutes` 의미를 변경하지 않습니다.

### 안전 여유 (`safetyBufferMinutes`)

추천 여정이 입력 시간을 꽉 채우지 않도록 마지막에 남겨두는 시간입니다. 현재 선택값은 10분, 15분, 20분, 30분입니다.

### 평균 머무름 (`stayMinutes`)

장소 유형별 기본 체류시간입니다. 개별 사용자의 실제 체류시간을 보장하지 않으며 카드에는 `평균 머무름`으로 표시합니다.

### 예상 총시간과 남는 시간

- 한 장소 추천은 백엔드가 두 이동 구간과 머무름을 합산합니다.
- 여러 경유지를 동시에 선택한 결과는 각 단일 추천의 우회·체류시간을 앱에서 합산한 예상값입니다.
- 복수 경유지 전체를 Kakao Mobility로 다시 계산하지 않습니다.
- 따라서 복수 선택 화면에는 반드시 `예상` 또는 동일한 의미의 표현을 유지합니다.

## 5. 추천 의도

현재 추천 의도 선택은 학습형 개인화가 아니라 TourAPI 카테고리 필터입니다.

| 사용자 선택 | 동작 |
|---|---|
| 아무거나 | 카테고리 제한 없음 |
| 식사 | 음식점 |
| 카페 | 카페 카테고리 요청 |
| 산책·관광 | 관광지·레포츠 |
| 실내 활동 | 문화시설·쇼핑 |
| 지금은 음식 제외 | 음식점·카페 제외 |

현재 TourAPI 수집에서 음식점이 모두 `RESTAURANT`로 들어갈 수 있어 `CAFE` 데이터 품질은 개선이 필요합니다.

## 6. 장소 데이터 범위

TourAPI `KorService2`, `areaCode=32`의 다음 유형을 수집합니다.

- 관광지
- 문화시설
- 축제·공연·행사
- 레포츠
- 쇼핑
- 음식점

대표 이미지, 주소, 좌표, 운영시간, 휴무일과 일부 편의 태그를 상세 동기화합니다. 고령자 동반·무장애 시설은 아직 별도 데이터 연동 전입니다.

## 7. 제품에서 보장하지 않는 것

- 목적지 도착을 100% 보장하지 않습니다.
- 도보 시간은 실시간 보행 경로가 아닙니다.
- 복수 경유지의 앱 내 총시간은 통합 실시간 경로가 아닙니다.
- 붉은 후보 영역은 실제 등시간 도달 영역이 아닙니다.
- 영업시간 정보가 없으면 영업 여부를 확정하지 않습니다.
- 카카오맵 실행 후 교통 상황과 경로가 달라질 수 있습니다.
- 저장 장소는 현재 계정 간 동기화되지 않습니다.

사용자 문구는 `시간 내 방문 가능한 예상 추천`, `운영시간 확인 필요`, `도보 시간은 예상값`처럼 한계를 드러내야 합니다.

## 8. 현재 출시 범위

### MVP에 포함

- Android 앱
- 두 탐색 모드
- GPS와 장소 검색
- 시간·안전 여유·추천 의도
- TourAPI 장소 추천
- 지도 후보와 최대 5개 경유지 선택
- 카카오맵 연결
- 장소 둘러보기·기기 로컬 저장
- 기본 설정과 문의 메일

### 다음 테스터 버전 후보

- 결과 상단 총 소요시간·경유지 수 카드
- 지도 위 대표 이미지 카드 캐러셀
- 기본 이동시간과 순수 여유시간의 의미 확정
- 복수 경유지 통합 경로 재계산
- 실제 경로 기반 후보 영역
- 저장 탭의 목적과 명칭 정리

### Play Store 제출 전 필수

- 개인정보처리방침과 위치기반서비스 관련 공개 문서
- 앱 아이콘·스플래시·스크린샷·스토어 문구
- 접근성 검토
- 릴리스 서명과 AAB
- Play App Signing
- 데이터 보안 설문과 위치 권한 고지
- 실제 기기 회귀 테스트
